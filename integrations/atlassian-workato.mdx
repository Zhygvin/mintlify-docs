## Core Workato Recipes

Build these five recipes to automate the full lead-to-close motion.

### Recipe 1: Inbound Lead Capture

| Field | Value |
| --- | --- |
| Trigger | HTTP webhook on form submission from `/solutions/request-a-demo` |
| Enrichment | Clearbit or Apollo enrichment on company domain |
| Routing | Send to Genie for qualification scoring |
| Output | HubSpot contact + deal creation, Slack notification |

### Recipe 2: Lead Qualification by Genie

| Field | Value |
| --- | --- |
| Trigger | New HubSpot contact in "Inbound" lifecycle stage |
| Agent action | Genie reads enrichment data, calls DSS knowledge base, produces fit score 1-10 |
| Output | Updates HubSpot with fit score, segment tag, and routing recommendation |

### Recipe 3: Outbound Sequence Delivery

| Field | Value |
| --- | --- |
| Trigger | HubSpot contact tagged with buyer segment (fintech, crypto, compliance, ESG) |
| Agent action | Genie selects segment-specific email template from the outreach playbook |
| Output | Gmail/Outlook sends personalized sequence (3 emails, 5-day cadence) |

### Recipe 4: Partner Routing

| Field | Value |
| --- | --- |
| Trigger | Form submission to `/company/partner-program` |
| Agent action | Genie classifies partner tier (referral, reseller, integrator, OEM) |
| Output | Routes to `partnerships@neoxz.engineering`, creates HubSpot deal with tier tag |

### Recipe 5: Weekly Attribution Report

| Field | Value |
| --- | --- |
| Trigger | Cron: every Monday at 9am UTC+8 |
| Agent action | Pulls HubSpot deals, Mintlify analytics, Workato recipe logs |
| Output | Posts summary to Confluence page in NeoXZ space + Slack digest |

## Atlassian Forge App (Planned)

A native Confluence and Jira app that embeds DSS continuous authentication into the Atlassian workspace is on the Q1 2027 roadmap.

Planned capabilities:

- Continuous DSS handshake validation for Confluence page access
- Trust-score-gated Jira issue transitions (e.g., require score greater than 0.90 to close security tickets)
- Attestation report generation from Confluence into the compliance log
- Bridge integration using Atlassian Forge platform APIs

<Note>
  Reference: [Atlassian Forge Bridge documentation](https://developer.atlassian.com/platform/forge/extend-ui-with-custom-options/#bridge). The planned Forge app will use the bridge to render DSS trust-score indicators in the Atlassian UI.
</Note>
