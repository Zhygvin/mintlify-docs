## How It Works

NEOXZ is built around a simple, linear flow that developers can get productive with in minutes while the sovereign mesh validates every request behind the scenes:

<Steps>
  <Step title="Authenticate">
    Generate an API key from your dashboard and include it as a Bearer token in every request. DSS handshakes continuously validate the session.
  </Step>
  <Step title="Call the API">
    Use the REST API to create, read, update, and delete resources in your NEOXZ workspace.
  </Step>
  <Step title="Receive webhooks">
    Subscribe to events so NEOXZ can push real-time updates to your server whenever something changes.
  </Step>
  <Step title="Iterate">
    Explore advanced capabilities, tune your configuration, and expand what your integration can do.
  </Step>
</Steps>
