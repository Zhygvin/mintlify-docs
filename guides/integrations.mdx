NeoXZ integrates with your existing tech stack through its REST API and webhook system. Whether you're calling NeoXZ from your backend, automating workflows with no-code tools, or reacting to real-time events, this guide covers the patterns you need to get connected quickly.

## REST API Integration

You can call the NeoXZ REST API from any language or environment that can make HTTP requests. All endpoints accept JSON request bodies and return JSON responses. Authenticate every request with your API key in the `Authorization` header.

The example below fetches a list of resources from your workspace:

<CodeGroup>

```javascript JavaScript
const response = await fetch("https://api.neoxz.com/v1/resources", {
  method: "GET",
  headers: {
    "Authorization": `Bearer ${process.env.NEOXZ_API_KEY}`,
    "Content-Type": "application/json",
  },
});

const data = await response.json();
console.log(data.resources);
```

```python Python
import os
import requests

response = requests.get(
    "https://api.neoxz.com/v1/resources",
    headers={
        "Authorization": f"Bearer {os.environ['NEOXZ_API_KEY']}",
        "Content-Type": "application/json",
    },
)

data = response.json()
print(data["resources"])
```

```bash curl
curl -X GET https://api.neoxz.com/v1/resources \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json"
```

</CodeGroup>

A successful call returns a `200 OK` response with a paginated list of resources. Use the `page` and `limit` query parameters to navigate through large result sets.

## Webhook Integration

Webhooks let NeoXZ push real-time event notifications to your server the moment something happens in your workspace — no polling required. When an event fires, NeoXZ sends an HTTP `POST` request to the endpoint URL you registered, with a JSON body describing the event.

**Available events:**

| Event | Triggered when |
|---|---|
| `resource.created` | A new resource is created in your workspace. |
| `resource.updated` | An existing resource is modified. |
| `resource.deleted` | A resource is permanently deleted. |
| `resource.failed` | A resource transitions to a failed state. |
| `quota.warning` | Your workspace reaches 80% of a resource quota. |

**Example webhook payload:**

```json
{
  "id": "evt_01hx9k2m3n4p5q6r7s8t9u0v",
  "type": "resource.created",
  "created_at": "2024-05-10T14:32:00Z",
  "workspace_id": "ws_abc123",
  "data": {
    "resource": {
      "id": "res_def456",
      "name": "my-resource",
      "status": "active",
      "labels": ["production"],
      "metadata": {
        "owner": "platform-team"
      },
      "created_at": "2024-05-10T14:32:00Z"
    }
  }
}
```

## Setting Up a Webhook

<Steps>
  <Step title="Open the Webhooks settings">
    In your NeoXZ dashboard, navigate to **Settings** → **Webhooks**.
  </Step>

  <Step title="Add a new endpoint">
    Click **Add Endpoint**. A configuration panel slides open on the right.
  </Step>

  <Step title="Enter your endpoint URL">
    Type or paste the public HTTPS URL where NeoXZ should deliver events (e.g., `https://yourapp.com/webhooks/neoxz`). The URL must be publicly reachable — localhost URLs will not work in production.
  </Step>

  <Step title="Select events">
    Check the events you want to subscribe to. You can select individual events or click **Select All** to receive every event type.
  </Step>

  <Step title="Save and verify">
    Click **Save Endpoint**. NeoXZ immediately sends a `webhook.test` ping to your URL — check your server logs to confirm it arrives. Your endpoint is now active and will receive live events.
  </Step>
</Steps>

Once your endpoint is registered, handle incoming events in your server. Here's a minimal Node.js / Express handler:

```javascript
import express from "express";

const app = express();
app.use(express.json());

app.post("/webhooks/neoxz", (req, res) => {
  const event = req.body;

  switch (event.type) {
    case "resource.created":
      console.log("New resource created:", event.data.resource.id);
      break;
    case "resource.failed":
      console.error("Resource failed:", event.data.resource.id);
      break;
    default:
      console.log("Unhandled event type:", event.type);
  }

  // Acknowledge receipt immediately
  res.status(200).json({ received: true });
});

app.listen(3000);
```

<Warning>
  Always verify the webhook signature before processing an event. NeoXZ signs every request with an `X-NeoXZ-Signature` header derived from your endpoint's secret. Skipping this check leaves your endpoint vulnerable to spoofed requests from malicious actors. Compare the computed HMAC-SHA256 signature of the raw request body against the header value before trusting any payload.
</Warning>
