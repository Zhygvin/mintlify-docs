## Get Up and Running

Follow these three steps to go from zero to your first successful API call.

<Steps>
  <Step title="Create Your Account">
    Head to [app.neoxz.com](https://app.neoxz.com) and sign up for a free account. Confirm your email address to activate your workspace.
  </Step>
  <Step title="Get Your API Key">
    Once you're logged in, navigate to **Settings → API Keys** and click **New Key** to generate your first API key. Copy it somewhere safe — you'll need it in the next step.
  </Step>
  <Step title="Make Your First API Call">
    Use your API key to authenticate a request to the NeoXZ API. Pass it as a Bearer token in the `Authorization` header and you're ready to start building.
  </Step>
</Steps>
